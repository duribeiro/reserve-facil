# Etapa 4e. Alta fidelidade

**Objetivo:** Levar todas as telas do wireframe aprovado para a alta fidelidade, usando só o design system, com protótipo clicável.

| | |
|---|---|
| Entra | O wireframe aprovado, o design system aprovado e as imagens de conteúdo. |
| Sai | Todas as telas em alta fidelidade, o protótipo clicável e a lista de telas com o veredito do dono. |
| Quem decide | O dono aprova jornada por jornada. |
| Roteiro do agente | [prompt.md](prompt.md) |

**Critério de aceite:** toda tela do wireframe tem versão em alta fidelidade feita só com o design system, o protótipo navega por todas as jornadas, e o dono aprovou cada jornada.

Regras que valem em toda etapa: [pipeline/README.md](../README.md) e [question-principles.md](../question-principles.md).
