# 2. SaaS ReserveFacil, protótipo para o Ulivo

**Estado:** em vigor. Relacionada à [1](../interface/0001-marca-ulivo-cores-e-fontes.md).

## Decisão

ReserveFácil é o nome do produto (SaaS). Cada restaurante contrata e recebe uma implementação personalizada com a marca dele. Este protótipo cobre uma única implementação, para o restaurante fictício Ulivo. Cadastro de restaurantes e painel de várias marcas ficam fora do protótipo. Logo, cores e fontes são tratados como elementos trocáveis.

## Por quê

A turma descreveu um sistema para restaurantes em geral. O dono quer mostrar um caso concreto sem perder a estrutura reutilizável.
