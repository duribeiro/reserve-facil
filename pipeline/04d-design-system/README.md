# Etapa 4d. Design system

**Objetivo:** Transformar a amostra escolhida num sistema reutilizável, para que toda tela nova saia igual sem decidir cor, fonte e componente de novo.

| | |
|---|---|
| Entra | A amostra escolhida na etapa 4c e a decisão registrada. |
| Sai | Uma página de design system na ferramenta de desenho, com variáveis e componentes, e `pipeline/04d-design-system/design-system.md` descrevendo cada item. |
| Quem decide | O agente monta. O dono aprova a página. |
| Roteiro do agente | [prompt.md](prompt.md) |

**Critério de aceite:** todas as cores, fontes, espaçamentos e componentes usados na amostra escolhida existem como variável ou componente, e o documento descreve quando usar cada um.

Regras que valem em toda etapa: [pipeline/README.md](../README.md) e [question-principles.md](../question-principles.md).
